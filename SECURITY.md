# Security policy

Report a vulnerability privately through a GitHub security advisory on this repository, or through [versatile.sh/contact](https://versatile.sh/contact). Do not open a public issue for it.

Include the affected cask and version, the steps to reproduce, and the impact you observed. You get an acknowledgement, and a fix or a decision is shared with you before any public disclosure.

A cask here points at a release archive of a Versatile project and pins its SHA-256 checksum. A checksum mismatch on install is a security problem: report it and do not work around it.
